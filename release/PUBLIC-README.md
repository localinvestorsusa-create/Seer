# Seer

Seer is a Windows screen recorder. It records the primary display with computer and microphone audio, then saves MP4 files in Downloads.

Download the latest Windows installer from [Releases](https://github.com/localinvestorsusa-create/Seer/releases/latest). After installation, Seer checks this page for app updates while running.

FFmpeg is installed separately the first time you use Seer.
